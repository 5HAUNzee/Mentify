📘 Mentify – Digital Mentorship Management System

Mentify is a mobile-first digital mentorship management application designed to replace slow, paper-based mentorship workflows in educational institutions.
It provides a centralized, secure, and user-friendly platform for students, mentors, and administrators to manage mentorship forms, communication, and progress tracking efficiently.

🚀 Abstract

The Mentify application digitizes the traditional mentorship form submission system found in many colleges and universities.
By providing a mobile and web-based platform, it eliminates manual work, reduces data errors, and ensures real-time access to mentorship progress.

The solution supports:

Accurate, organized record-keeping

Smooth communication between mentors and students

Centralized data access for administrators

Reduced paper usage and improved sustainability

Improved efficiency through digital workflows

Mentify modernizes the mentorship management process and enhances the overall experience for students, mentors, and institutions.

❗ Problems Addressed
1. Administrative Overload

Manual form distribution, collection, and sorting consumes time and resources, slowing down academic workflows.

2. Data Inaccuracy & Loss

Handwritten entries are prone to errors, and physical forms can be lost, damaged, or misplaced.

3. No Real-time Access or Tracking

Traditional systems lack immediate updates, making progress tracking and feedback slow and inefficient.

4. Security & Privacy Risks

Paper forms are not secure and can be accessed by unauthorized individuals.

5. Environmental Impact

Excessive paper usage contradicts modern sustainability goals.

⭐ Core Features
✅ Cross-platform Accessibility

Accessible on mobile (React Native) and web, ensuring availability anytime, anywhere.

🔄 Auto Matching Logic

Automatically pairs mentors with mentees based on interests, academic background, and form inputs.

🔐 Secure & Real-time Sync

Powered by Firebase for instant updates, authentication, and secure data handling.

📊 Insight-Driven Admin Dashboard

Admins receive useful analytics, insights, and organized mentorship records semester-wise.

⚙️ Scalable & Customizable

Designed to adapt to different institutions, workflows, and mentorship models.

▶️ How to Run the Project (React Native)
1. Install Dependencies
npm install

2. Start Metro Server
npm start

3. Run on Android
npm run android

4. Run on iOS (Mac only)
npm run ios

🔒 Security Considerations

Firebase Authentication ensures secure login

Role-based access: Admin, Mentor, Student

Encrypted cloud storage for all form data

Controlled database rules to prevent unauthorized access
